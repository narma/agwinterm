# Agwinterm 0.30.10 — Session selection keeps the Agents panel collapsed

Selecting a session in the sidebar keeps the Agents panel collapsed if you closed it. Expand the panel to see the selected session's agent.

## Downloads

| Download | Use it for |
| --- | --- |
| `agwinterm-setup-0.30.10.exe` | Standard .NET 11 installation |
| `agwinterm-portable-0.30.10-win-x64.exe` | Portable .NET 11 application |
| `agwintermctl.exe` | Standalone .NET 11 control CLI |
| `agwinterm-net10-setup-0.30.10.exe` | .NET 10 installation |
| `agwinterm-net10-portable-0.30.10-win-x64.exe` | Portable .NET 10 application |

All downloads are self-contained. The `agwinterm-net11-` files are compatibility aliases for older .NET 11 builds.

Save your work before upgrading with the installer. It stops the existing session host and ends any Windows programs running in it.
