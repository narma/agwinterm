# Agwinterm 0.30.12 — Activity log and WSL conversation rename fix

- Fixed a Windows line-ending issue that could prevent Codex and Claude Code conversations from being renamed in WSL.
- Open **Activity log** from the command palette to review and copy diagnostic entries from Agwinterm and its session host. The log is kept across restarts, so you can look up errors after their notifications disappear.

## Downloads

| Download | Use it for |
| --- | --- |
| `agwinterm-setup-0.30.12.exe` | Standard .NET 11 installation |
| `agwinterm-portable-0.30.12-win-x64.exe` | Portable .NET 11 application |
| `agwintermctl.exe` | Standalone .NET 11 control CLI |
| `agwinterm-net10-setup-0.30.12.exe` | .NET 10 installation |
| `agwinterm-net10-portable-0.30.12-win-x64.exe` | Portable .NET 10 application |

All downloads are self-contained. The `agwinterm-net11-` files are compatibility aliases for older .NET 11 builds.

Save your work before upgrading with the installer. It stops the existing session host and ends any Windows programs running in it.
