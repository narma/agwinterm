# Agwinterm 0.30.6 — Stable scrollback and more reliable keyboard input

## Terminal scrollback

- The terminal keeps your place while you read earlier output, even as new lines arrive. When you're at the bottom, the terminal follows new output automatically. This is the default (`follow-output = bottom`).
- Set `follow-output = always` in the terminal configuration to jump to the latest output when new lines arrive.

## Keyboard input

- Applications using the Kitty keyboard protocol now receive more accurate key events for the active Windows keyboard layout, including characters typed with AltGr and Shift.
- Left and right modifiers are reported separately, and releasing both Shift keys clears their pressed state even if Windows omits one release event.
- Print Screen works when Windows sends only the key release.
