# Agwinterm 0.30.5 — .NET 11 by default, faster session restore

Agwinterm now ships with the stable .NET 11 runtime. This release also makes restoring a workspace more responsive and adds startup diagnostics for investigating slow launches.

## .NET 11 is the default

The standard installer, portable application and standalone CLI now use **.NET 11**, with ReadyToRun and runtime async enabled across the application, session host and CLI. All downloads are self-contained: **you do not need to install .NET separately**.

**.NET 10 remains a supported option**, available through the explicitly named `agwinterm-net10-` downloads.

### How automatic updates choose a runtime

| Currently running Agwinterm | Runtime after updating |
| --- | --- |
| .NET 10 build, version **0.30.5 or newer** | **.NET 10** |
| .NET 10 build, version **0.30.4 or older** | **.NET 11** |
| Any .NET 11 build | **.NET 11** |

The rule applies to installed and portable copies. To stay on .NET 10, explicitly install the .NET 10 edition of **0.30.5 or newer**; subsequent in-app updates preserve that choice. Package-manager installations continue to be updated by their package manager.

## Faster, more reliable startup

- **Earlier startup feedback.** The window paints before session restoration begins and shows progress while restoring a workspace. New session starts are queued, reducing synchronous work during restoration.
- **Startup timing diagnostics.** Startup events and timings make it easier to identify where a slow launch spends its time.
- **Smoother first frames.** Restored terminals defer work until their presentation is ready, reducing unnecessary work during startup.

## Choose your download

| Download | Use it for |
| --- | --- |
| `agwinterm-setup-0.30.5.exe` | Recommended .NET 11 installation |
| `agwinterm-portable-0.30.5-win-x64.exe` | Portable .NET 11 application |
| `agwintermctl.exe` | Standalone .NET 11 control CLI |
| `agwinterm-net10-setup-0.30.5.exe` | Supported .NET 10 installation |
| `agwinterm-net10-portable-0.30.5-win-x64.exe` | Portable .NET 10 application |

The `agwinterm-net11-` files contain the same .NET 11 builds as the standard downloads. These compatibility names allow older .NET 11 installations to update normally.

**Before upgrading:** the full installer saves application state and stops the old session host. Running Windows programs end during this upgrade; saved layout, settings and available terminal history are restored on the next launch.
