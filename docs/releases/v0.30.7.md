# Agwinterm 0.30.7 — Terminal selection and Agents sidebar fixes

## Terminal selection

- Double-click word selection clears correctly when you click elsewhere in the terminal. Selection highlighting is steadier when clicking and dragging in hosted sessions.

## Agents sidebar

- Agent rows clear when the agent exits and control returns to the shell, including pinned and completed rows.
- Each agent row uses the title of its own pane when the agent has no title and the session has no custom name.
- When the app reconnects to the same hosted shell after a GUI restart, unread completions stay unread and read completions stay read.
