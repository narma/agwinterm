# Agwinterm 0.30.8 — Sidebar navigation and terminal input during restore

## Sidebar

- Selecting an agent also selects its session. The Agents and Sessions lists scroll independently.
- Copy a conversation, pane, or session ID from the sidebar. Codex rows show a hint when a conversation ID is unavailable.

## Terminal input

- You can type in the active pane while other sessions are still restoring. Input typed before the local PTY connects is queued.
- Fixed standalone Shift key handling in ConPTY sessions.

## Integrations

- Installed WSL integrations refresh on the first profile launch after an update.
- Agents now need explicit opt-in to write session context. The Claude Code update integration has been removed.

| Download | Use it for |

Save your work before upgrading with the installer. It stops the existing session host and ends any Windows programs running in it.
