# Agwinterm 0.30.11 — Rename agent conversations from the sidebar

- Rename a Codex or Claude Code conversation from the Agents context menu or press F2 on its session in the sidebar. The new title is saved in the agent's conversation history and shown in both sidebar lists.
- Renaming works for supported conversations on Windows and in WSL. In split sessions, F2 renames the conversation in the active pane. The title is preserved on reconnect.

## Downloads

| Download | Use it for |
| --- | --- |
| `agwinterm-setup-0.30.11.exe` | Standard .NET 11 installation |

Save your work before upgrading with the installer. It stops the existing session host and ends any Windows programs running in it.
